# SECURITY BOUNDARIES

This project intentionally simulates hacking and malware concepts without implementing real-world offensive capability.

## Allowed
- fictional commands;
- fictional credentials;
- fictional IP/node identifiers;
- simulated vulnerabilities as puzzles;
- simulated malware/payload state transitions;
- fictional trace meters;
- fake logs and evidence;
- sandboxed in-game network graphs.

## Forbidden in the game code
- executing arbitrary host shell commands from gameplay;
- real credential collection;
- real network scanning or exploitation;
- persistence on the host machine;
- real malware or destructive payloads;
- credential theft from the player or external services;
- connecting mission systems to real targets.

## Design goal
The terminal should feel authentic because of presentation, pacing, vocabulary, evidence and consequences—not because it performs real attacks.
