# GAMEPLAY

## Core loop
**Explore → Observe → Interact → Investigate → Decide → Escape → Consequence**

## World
Top-down 2D exploration with a compact initial district. The player can move through streets, buildings, industrial spaces and resistance locations.

## Interaction
Objects can expose clues, resources, hazards or terminals. Not every interaction should become a combat encounter.

## Terminal gameplay
Terminals provide a fictional command-line environment. The player can inspect files, navigate simulated networks, solve puzzles, authenticate using in-game credentials and execute fictional payload sequences.

## Threats
Threats include patrols, drones, surveillance, hostile environments, human factions and AI-controlled systems. Avoid making combat the only meaningful interaction.

## Decisions
Some actions alter trust, available information, mission outcomes and later dialogue. The player should sometimes have to act without knowing which source is truthful.

## Progression
Progression should primarily unlock access, knowledge, relationships and capabilities rather than simple numerical power.
