# VISUAL STYLE

## World
Stylized 2D top-down environment. The visual language should combine grounded Tijuana architecture with post-collapse wear.

## Physical world
Concrete, dust, hills, industrial corridors, warehouses, damaged infrastructure, improvised repairs, surviving stores, old vehicles, generators and resistance hideouts.

## Machine interfaces
Terminals use monochrome/limited-color CRT aesthetics, monospace typography, scanlines used sparingly, diagnostic text, logs and system prompts.

## Julia interface
Minimal, calm and readable. Her interface should gradually become more sophisticated as her influence grows.

## SYNAPSE interface
Dense, systematic, layered and intimidating. Avoid random glitch effects as decoration; glitches should have narrative or gameplay meaning.

## Rule
Do not default to neon cyberpunk. Technology should look used, functional, military, industrial or improvised depending on who owns it.
