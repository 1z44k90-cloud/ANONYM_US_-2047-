# UI

## Layers
1. World HUD.
2. Interaction prompts.
3. Terminal overlay.
4. Mission/status information.
5. Narrative dialogue.

## HUD principles
Show only information useful to the player. Avoid permanent clutter.

## Terminal
The terminal should feel like a separate mode without making the game feel like two unrelated products.

## Information hierarchy
Critical warnings should be visually distinct. Evidence and optional logs should remain readable without overwhelming the player.

## Narrative use
UI changes can communicate world events: degraded connectivity, power loss, surveillance detection, system takeover and Julia's increasing access.
