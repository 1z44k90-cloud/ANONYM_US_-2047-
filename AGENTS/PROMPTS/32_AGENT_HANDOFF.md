# TASK 32 — HANDOFF OBLIGATORIO

## Objective
Make every completed task independently continuable by another agent.

## Required handoff
State:
- completed work;
- exact files changed;
- verification actually performed;
- known limitations;
- unresolved blockers;
- decisions created/changed;
- current phase/status;
- exact next task.

## Acceptance criteria
Another agent can continue without reconstructing essential context from conversation history.
