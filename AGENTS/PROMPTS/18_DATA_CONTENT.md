# TASK 18 — CONTENIDO DATA-DRIVEN

## Objective
Add mission, dialogue, world or gameplay content as data without unnecessarily changing engine code.

## Required reading
- `AGENTS/MASTER_CONTEXT.md`
- `AGENTS/PROJECT_STATUS.md`
- `AGENTS/DECISIONS.md`
- relevant design documentation
- relevant content schema
- GitHub issue

## Task
Create or modify content using the project's established data format and identifiers. Keep narrative/content decisions separate from engine implementation.

## Acceptance criteria
- Content follows the documented schema.
- IDs and references are valid.
- Content does not contradict established canon.
- Validation/tests pass where available.
- No unrelated engine refactor is introduced.

## Handoff
Report content added, identifiers, validation performed, dependencies and next content task.
