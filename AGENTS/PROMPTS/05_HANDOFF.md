# TASK 05 — HANDOFF / CIERRE DE TAREA

## Objective
Standardize the final report an agent leaves for the next agent.

## Required handoff
Every completed task must leave a concise record containing:

### 1. Result
What was actually implemented or decided.

### 2. Files changed
Exact repository paths.

### 3. Verification
Commands/checks/tests executed and their result.

### 4. Known limitations
Anything intentionally incomplete or deferred.

### 5. Decisions
Any architectural, gameplay or process decisions created or changed.

### 6. Status
Whether the current phase or next task changed.

### 7. Next task
The smallest high-value task that can continue from the current state.

## Rule
Do not describe planned work as completed work. Distinguish clearly between implemented, verified, blocked and deferred items.
