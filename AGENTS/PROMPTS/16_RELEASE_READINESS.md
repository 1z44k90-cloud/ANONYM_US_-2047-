# TASK 16 — RELEASE READINESS

## Objective
Determine whether a build is ready for a defined release milestone without confusing feature completeness with readiness.

## Required reading
- `AGENTS/MASTER_CONTEXT.md`
- `AGENTS/PROJECT_STATUS.md`
- `AGENTS/DECISIONS.md`
- `AGENTS/TASK_PROTOCOL.md`
- release-related technical/design documentation

## Checks
- [ ] Current phase Definition of Done is satisfied.
- [ ] Build/package process is reproducible.
- [ ] Critical gameplay path is verified.
- [ ] Known critical bugs are resolved or explicitly accepted.
- [ ] Documentation matches the shipped state.
- [ ] Platform-specific constraints are understood.
- [ ] Safety boundaries remain intact.

## Rule
A release-readiness task evaluates evidence. It does not automatically authorize new scope.

## Handoff
Report readiness status, evidence, blockers, known risks and recommended release or stabilization tasks.
