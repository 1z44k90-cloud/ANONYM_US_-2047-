# TASK 24 — PULL REQUEST DEFINITION

## Objective
Create a reviewable pull request for a completed task branch.

## Required reading
- `AGENTS/MASTER_CONTEXT.md`
- `AGENTS/PROJECT_STATUS.md`
- `AGENTS/DECISIONS.md`
- `AGENTS/TASK_PROTOCOL.md`
- `AGENTS/PROMPTS/06_REVIEW_CHECKLIST.md`

## PR body must state
- objective;
- implementation summary;
- files/systems affected;
- tests actually executed;
- documentation updated;
- known limitations;
- architectural decisions, if any;
- next task.

## Acceptance criteria
- PR targets `main`.
- PR description is factual and traceable to the task prompt.
- No unverified claims are made.
- Review checklist has been considered before merge.
