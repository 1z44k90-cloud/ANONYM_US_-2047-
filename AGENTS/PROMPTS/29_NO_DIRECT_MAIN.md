# TASK 29 — PROTECCIÓN DE MAIN

## Objective
Ensure agents understand that `main` is an integration target, not a working area.

## Rule
Do not implement, experiment or partially develop assigned work directly on `main`.

Use a dedicated branch and submit a pull request. The only exception is a deliberately authorized maintenance operation that has no suitable branch workflow; such an exception must be explicit and documented.

## Acceptance criteria
Any agent reading this prompt can identify the expected branch workflow before making changes.
