# TASK 11 — DOCUMENTATION CHANGE

## Objective
Make a controlled documentation-only change without altering gameplay or architecture unintentionally.

## Required reading
- `AGENTS/MASTER_CONTEXT.md`
- `AGENTS/PROJECT_STATUS.md`
- `AGENTS/DECISIONS.md`
- `AGENTS/TASK_PROTOCOL.md`
- relevant document(s)

## Task
Update only the requested documentation. Preserve existing valid decisions and terminology. If the requested wording reveals a contradiction, use the conflict protocol instead of silently rewriting the project.

## Acceptance criteria
- Requested documentation is complete and internally consistent.
- No unrelated code or design was changed.
- Any new durable decision is recorded in `AGENTS/DECISIONS.md`.

## Verification
Review the changed documents against the master context, project status and decision log.

## Handoff
Report exact documents changed, consistency checks performed and any remaining ambiguity.
