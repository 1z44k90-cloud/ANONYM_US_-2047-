# TASK 17 — INVESTIGACIÓN PARA DECISIÓN

## Objective
Research an unresolved project decision without directly changing implementation.

## Required reading
- `AGENTS/MASTER_CONTEXT.md`
- `AGENTS/PROJECT_STATUS.md`
- `AGENTS/DECISIONS.md`
- relevant technical/design documentation
- GitHub issue

## Task
Gather evidence relevant to the decision, compare alternatives against the project's actual constraints, and produce a recommendation. Do not implement the recommendation in the same task unless explicitly assigned.

## Acceptance criteria
- The decision question is explicit.
- Alternatives are compared using project-specific criteria.
- Evidence and assumptions are distinguished.
- Recommendation includes trade-offs.
- No implementation was changed without authorization from the task scope.

## Handoff
Provide the recommendation, evidence, rejected alternatives, risks and exact follow-up implementation task.
