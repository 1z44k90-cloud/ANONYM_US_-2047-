# TASK 30 — DEFINITION OF DONE

## Objective
Provide a universal completion standard for repository tasks.

## A task is DONE only when
- [ ] The stated objective is achieved.
- [ ] Acceptance criteria pass.
- [ ] Required tests/verification were actually executed.
- [ ] No known critical regression remains.
- [ ] Scope stayed within the task.
- [ ] Relevant documentation is synchronized.
- [ ] Decisions are recorded when needed.
- [ ] Project status is updated when needed.
- [ ] Handoff is complete and factual.

## Important
Code existing in the repository is not evidence by itself that a task is complete.
